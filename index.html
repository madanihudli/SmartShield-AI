Model integrity & limitations

TRANSPARENCY

The model uses lexical features extracted from URL text. It does not fetch HTML, inspect page source, check certificate reputation, query DNS, or use live threat feeds. Dataset results may be affected by collection bias, repeated domains and changes in attacker behaviour. The message scanner currently uses explainable rules rather than a trained NLP classifier.

TRANSPARENCY CENTER

Privacy & data policy

How this local prototype handles submitted content, scan records and feedback.

LOCAL-FIRST DESIGN
SMARTSHIELD AI · PROTOTYPE PRIVACY NOTICE · UPDATED 21 NOVEMBER 2026

01. Information processed

Content entered into the scanner is sent to the Flask server running this application on your computer for analysis. Screenshot OCR, when configured, processes the uploaded image locally. Browser voice dictation relies on browser-provided speech recognition and may be subject to the browser provider's own practices.

02. Purpose of processing

Submitted text and URL strings are used to produce a risk assessment, feature indicators and recommended next steps. URL destinations are not opened or fetched by the scanner.

03. Local storage and scan history

If scan-history saving is enabled, scan metadata, a short content preview and the report are stored in a SQLite database named smartshield.db in the project folder. You can disable history saving, clear scan records or export them as CSV.

04. Feedback

Feedback messages and optional email addresses are stored in the same local database. Do not include passwords, OTPs, payment data or other sensitive information in feedback.

05. Sharing and external services

The local application code does not intentionally send scan content to an external threat-intelligence provider or advertising analytics service. The optional one-time UCI dataset download and CDN-hosted fonts/chart library require internet access. Your operating system, browser, network or extensions may have separate data practices.

06. Retention and deletion

Use the History page to clear scan records. Feedback records are not currently removable through the UI. To remove all local prototype data, stop the server and delete smartshield.db from the project folder. This also removes saved preferences.

07. Security limitations

This is an educational prototype. It does not include production authentication, role-based access, hardened deployment, comprehensive audit controls or a formal security review. Anyone with access to the computer and project folder may be able to access stored records.

08. Public deployment

Before public deployment or real-user collection, add authentication and authorization, CSRF protection, secure session handling, rate limiting, HTTPS, hardened hosting, retention controls, incident response procedures and a privacy/legal review. This notice is descriptive and is not legal advice.

SUPPORT & DOCUMENTATION

Help center

Answers to common questions about SmartShield AI.

Does the URL scanner visit the submitted website?

No. The scanner extracts lexical features from the submitted URL string and does not open or fetch the destination.

Is the URL model already trained?

The ZIP contains a reproducible training script. Run python train_model.py after installing requirements and downloading the UCI dataset. Until then, the scanner uses a transparent lexical fallback.

What does a risk score mean?

It is a model score or heuristic screening score, not a calibrated probability of fraud. Treat it as one signal and verify unexpected requests independently.

Why is screenshot OCR unavailable?

Install Pillow, pytesseract and the separate Tesseract OCR engine. If that is not configured, paste the screenshot text into Message Analysis.

Does message scanning use NLP?

The current message scanner uses transparent phrase and pattern rules. A separately trained email/NLP model is a future extension; it is not claimed as implemented.

Can I deploy this for real customers?

Not without substantial security work. Add authentication, authorization, CSRF controls, secure sessions, rate limiting, HTTPS, logging, monitoring and a reviewed privacy notice.
